隐私与数据处理

你的数据如何被处理

本说明概述 SecNN 在线工具在浏览器本地处理、第三方请求及本地存储方面的基本行为。不同工具的具体行为可能有所差异。

浏览器本地处理

编解码、JWT、密码字典和部分文本转换功能主要在浏览器中运行。除非页面明确说明或功能需要调用外部接口，输入内容不会由本站主动提交到服务器。

第三方服务请求

IP 查询、Google 搜索、GitHub 查询等功能需要向相应第三方服务发送必要参数。第三方可能依据其隐私政策记录 IP 地址、查询内容、浏览器信息或访问日志。

浏览器本地存储

部分工具可能使用 localStorage 保存偏好、历史记录或用户主动填写的配置。共享设备上使用敏感信息后，请及时清除页面数据和浏览器存储。

敏感信息建议

  • 不要在在线工具中粘贴生产环境密钥、真实访问令牌或未脱敏的个人数据。
  • JWT 解码不等于签名可信，请独立验证签名、签发方、受众和有效期。
  • 仅对本人资产或已获得明确授权的目标开展安全测试。

外部资源

部分页面使用 CDN 字体、图标或 JavaScript 库。加载这些资源时，浏览器会直接连接对应服务提供方。

更新与反馈

本说明会随工具功能调整而更新。若发现页面行为与说明不一致，可通过 SecNN GitHub 项目反馈。
